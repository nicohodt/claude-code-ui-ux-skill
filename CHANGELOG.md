## [Unreleased]

### Fixed

- **Accessibility: 14 color palettes failed WCAG contrast.** `On Secondary` and `On Destructive` were set to white on mid-tone backgrounds, producing ratios as low as **2.28:1** — below even the 3:1 floor for large text and UI components. All 14 now use a dark foreground and clear **4.5:1**. Affected palettes: Notes & Writing App, Food Delivery, Weather App, Booking & Appointment, Grocery & Shopping List, Parenting & Baby Tracker, Expense Splitter, Calculator & Unit Converter, Running & Cycling GPS, Calorie & Nutrition Counter, Water & Hydration Reminder, Local Events & Discovery, Home Decoration & Interior Design, Open Source Project Landing.
- **Incorrect advertised counts.** The documentation claimed 98 UX guidelines and 104 icon entries; the database contains **99** and **105**. Corrected across both READMEs, `skill.json`, `cli/package.json`, the skill frontmatter, and the docs site. A regression test (`tests/test_advertised_counts.py`) now fails the build if the docs and the CSVs disagree.
- **`styles.csv` identifier gap.** The `No` column ran 1–85 with 54 missing across 84 rows. Renumbered to a contiguous 1–84 and enforced by a test.
- **CI ran zero tests.** The `Tests` workflow invoked `pytest .claude/skills`, but no Python tests existed anywhere in the repository — pytest exits non-zero when it collects nothing, so the workflow failed on every push.

### Added

- **Test suite — 192 tests.** Covers CSV structural integrity (ragged rows, duplicate columns, sequential identifiers, shared stack schema), WCAG contrast enforcement, search-engine behaviour across all 12 domains and 22 stacks, design-system generation, and documentation/database count consistency.
- **Rewritten `Tests` workflow.** Runs the suite on Python 3.9/3.11/3.13 on Linux plus 3.13 on macOS and Windows, alongside CSV validation, domain/stack smoke tests, CLI typecheck/build, an end-to-end `uipro init` check, and the Playwright preview tests.
- Project health files: `ROADMAP.md`, `SUPPORT.md`, `CONTRIBUTORS.md`, `CHANGELOG.md`, `LICENSE`, `.editorconfig`, `.github/CODEOWNERS`, `.github/dependabot.yml`, `.github/FUNDING.yml`.
- **Contributor onboarding.** A five-minute browser-only first-contribution path, a design-data issue template auto-labelled `good first issue`, an issue-template chooser, a first-time contributor welcome workflow, and a `scripts/seed-issues.sh` helper that files a starter set of good first issues.
- **Documentation site** at `docs/index.html` with Open Graph, canonical and `hreflang` tags plus JSON-LD (`SoftwareApplication`, `WebSite`, `FAQPage`), and `docs/SEO-CHECKLIST.md`.

### Changed

- **Project ownership** moved to [@nicohodt](https://github.com/nicohodt); the repository is now `nicohodt/claude-code-ui-ux-skill`. All references, badges, workflow guards and the CLI's release-download target were updated.
- **Claude marketplace id** is now `claude-code-ui-ux-skill`, so installation is `/plugin install ui-ux-pro-max@claude-code-ui-ux-skill`.
- **Removed the premium tier.** The project is fully open source under MIT with no paid version, no paywalled data and no upsell. The contributor pitch depends on this remaining true.
- Both READMEs rewritten for clarity and search visibility, with a parallel Chinese translation.
- `CONTRIBUTING.md` rewritten. It previously directed contributors to `rules.csv` and `ux.csv`, **neither of which exists** — the real files are `ui-reasoning.csv` and `ux-guidelines.csv`. Every recipe now carries the actual column schema.
- `cli/README.md` declared `CC-BY-NC-4.0` while the rest of the project is MIT. Corrected to MIT.
- semantic-release now comments on issues and pull requests when a release ships them (previously disabled), so contributors learn when their work goes live.

### Removed

- A broken hero image reference (`screenshots/website.png`) that had no corresponding file.
